Four parts of LPBF process control

Each step feeds the next. The map sets the starting window, the sensors check it, the controller adjusts it, and the record supports qualification.

  • Process windows

    Printability maps from a melt pool model calibrated on single tracks.

  • In-situ monitoring

    An infrared camera and an imaging pyrometer record every layer.

  • Adaptive parameters

    Power, speed and hatch spacing change by layer to hold a melt pool width.

  • Qualification

    Sensor records carry part of the evidence, so fewer test coupons get printed.

One LPBF build, from setup to finished part

How a print runs in Dr. Alaa Elwany’s lab at Texas A&M.

See the adaptive parameters project

  1. Set up the ProX 200

    I run builds on the lab’s 3D Systems machine and have built on EOS M290 and M400 machines.

  2. Watch the process, layer by layer

    Short tracks run hotter than long ones, and the gap grows with every layer. The sensor record shows where.

  3. Print the thin features

    Interlocking arms for Sandia, where the scan tracks shorten as the part rises and one fixed parameter set overheats them.

Grades composition in one LPBF build

Composition changes up the height of a single part, so each band transforms at its own temperature.

Most LPBF parameter sets are tuned once, on cubes. Real parts change cross-section every few layers, so I let the parameters change with them, guided by what the melt pool did on the layer before.
