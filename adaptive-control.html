Adaptive LPBF parameters for thin features

Short scan tracks overheat. I measure the melt pool layer by layer and reset power, speed and hatch so thin features build at the planned width.

Email TareshDownload résumé

Two failed trials at fixed process parameters

Sandia’s interlocking geometry at 240 W, 1200 mm/s and 25 µm hatch spacing. The thin arms slumped and took heavy heat tint.

The process control loop

  1. Calibrate on 2 to 50 mm tracks

    Single-layer tracks of different lengths calibrate a thermal model of melt pool width and depth.

  2. Measure each layer with 2 sensors

    An infrared camera and an imaging pyrometer record how heat builds up as the layers stack.

  3. Set the next layer’s process parameters

    An optimizer picks the power, speed and hatch that hold the target width, skipping keyhole and lack-of-fusion zones.

Clean LPBF prints in three versions

V1, V2 and V3 printed without a recoater strike, and V3 held its 420 µm target melt pool width over the full build height. In the lab, the same monitoring raised build yield by about 60%.
